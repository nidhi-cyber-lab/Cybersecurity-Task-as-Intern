# 10 Common Cyber Threats

## 1. Phishing

Phishing is a social engineering attack where an attacker sends a
fake email, message, or website to trick a person into providing
sensitive information.

**Example:**  
A person receives an email that looks like it is from their bank.
The email asks them to click a link and enter their username,
password, and OTP on a fake website.

---

## 2. Malware

Malware is malicious software designed to damage systems, steal
information, or perform unauthorized activities.

Examples include viruses, worms, spyware, and trojans.

**Example:**  
A user downloads a software application from an untrusted website.
The downloaded file contains malware that secretly steals files
from the computer.

---

## 3. Ransomware

Ransomware is malware that locks or encrypts a victim's files and
demands payment from the victim.

**Example:**  
An employee opens a malicious email attachment. Ransomware runs on
the computer and encrypts important documents. A message then
appears demanding payment to restore access to the files.

---

## 4. Password Attacks

Password attacks are attempts to obtain or guess a user's password.
Attackers may use methods such as password guessing, brute-force
attacks, or stolen credentials.

**Example:**  
A user has a weak password such as `123456`. An attacker guesses
the password and gains unauthorized access to the account.

---

## 5. Denial-of-Service (DoS)

A Denial-of-Service (DoS) attack attempts to make a service or
system unavailable by overwhelming it with requests or traffic.

**Example:**  
An attacker sends a very large number of requests to a company's
website. The server becomes overloaded, and legitimate customers
are unable to access the website.

---

## 6. Man-in-the-Middle (MitM)

A Man-in-the-Middle attack occurs when an attacker secretly
intercepts communication between two parties.

**Example:**  
A person connects to an unsecured public Wi-Fi network. An attacker
on the same network intercepts the communication between the user's
device and an online service.

---

## 7. SQL Injection

SQL Injection is an attack in which malicious SQL commands are
inserted into an application's input fields to manipulate a
database.

**Example:**  
A vulnerable login form does not properly validate user input.
An attacker enters specially crafted input that changes the
database query and may allow unauthorized access.

---

## 8. Insider Threat

An insider threat occurs when a person with authorized access,
such as an employee, misuses that access and causes security
problems.

**Example:**  
An employee with access to confidential company files copies
customer information and shares it with an unauthorized person.

---

## 9. Identity Theft

Identity theft occurs when someone obtains and misuses another
person's personal information.

**Example:**  
An attacker obtains someone's name, phone number, and other
personal information through a data breach and uses the information
to create a fraudulent account.

---

## 10. Social Engineering

Social engineering involves manipulating people into revealing
information or performing actions that compromise security.

**Example:**  
An attacker calls an employee pretending to be an IT support
person and convinces the employee to reveal their login
information.

---

## Conclusion

Cyber threats can affect both individuals and organizations.
Phishing, malware, ransomware, password attacks, DoS attacks,
Man-in-the-Middle attacks, SQL injection, insider threats, identity
theft, and social engineering are common examples.

Awareness, strong security practices, user education, software
updates, and proper security controls can help reduce cybersecurity
risks.
