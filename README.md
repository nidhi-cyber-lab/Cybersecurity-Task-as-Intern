## Task 1 -Introduction to cybersecurity
# Introduction-to-Cybersecurity
Introduction to cybersecurity, CIA triad, importance of cybersecurity, and common cyber threats.

## About the Project

This project provides an introduction to cybersecurity and explains
the basic concepts, importance, and common cyber threats faced by
individuals and organizations.

## Objectives

- Understand the basic concepts of cybersecurity.
- Understand the CIA Triad.
- Learn why cybersecurity is important.
- Identify common cyber threats.
- Understand basic security practices.

## Topics Covered

1. What is Cybersecurity?
2. CIA Triad
3. Importance of Cybersecurity
4. Personal Security Risks
5. Organizational Security Risks
6. Common Cyber Threats

## Deliverables

- Cybersecurity Notes
- List of 10 Common Cyber Threats

 ## Task 2 – CIA Triad Analysis

### Objective
To understand the three core principles of information security:
Confidentiality, Integrity, and Availability.

### Work Completed
- Explained the CIA Triad.
- Analyzed five real-world cybersecurity incidents.
- Classified each incident according to CIA principles.
- Included security lessons and prevention measures.

### Real-World Examples
1. Equifax Data Breach – Confidentiality
2. SolarWinds Supply-Chain Attack – Integrity
3. WannaCry Ransomware Attack – Availability
4. Colonial Pipeline Ransomware Attack – Availability
5. GitHub 2018 Incident – Availability and Integrity

### Deliverable
Report of CIA Triad Analysis with 5 Real life example 

## Conclusion

Cybersecurity helps protect information, systems, networks, and
users from unauthorized access, attacks, damage, and data loss.
Understanding basic cybersecurity concepts is important for both
individuals and organizations.
