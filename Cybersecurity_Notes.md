# Cybersecurity Notes

## 1. What is Cybersecurity?

Cybersecurity is the practice of protecting computers, networks,
applications, devices, and data from unauthorized access, attacks,
damage, or theft.

Cybersecurity is important because people and organizations store
large amounts of sensitive information digitally.

## 2. CIA Triad

The CIA Triad is a basic security model consisting of:

### Confidentiality

Confidentiality means protecting information from unauthorized
people.

Example:
Only authorized employees should be able to access confidential
company records.

### Integrity

Integrity means keeping information accurate, complete, and
protected from unauthorized modification.

Example:
An attacker should not be able to change the amount in a financial
transaction.

### Availability

Availability means making sure authorized users can access systems
and information when required.

Example:
An organization's website should remain available to legitimate
customers.

## 3. Importance of Cybersecurity

Cybersecurity is important because it helps:

- Protect personal information.
- Protect financial information.
- Prevent unauthorized access.
- Protect business data.
- Reduce the impact of cyber attacks.
- Maintain customer trust.
- Keep systems and services available.

## 4. Personal Security Risks

Individuals can face risks such as:

- Phishing
- Password attacks
- Malware
- Identity theft
- Online scams
- Data theft

## 5. Organizational Security Risks

Organizations may face:

- Data breaches
- Ransomware
- Insider threats
- Network attacks
- Phishing
- Malware
- Denial-of-service attacks

## 6. Basic Cybersecurity Practices

Some basic security practices include:

- Use strong and unique passwords.
- Enable multi-factor authentication.
- Keep software updated.
- Avoid suspicious links and attachments.
- Use trusted networks.
- Back up important data.
- Install security software.
- Do not share passwords.

## Conclusion

Cybersecurity is essential for protecting digital information,
systems, networks, and users. Understanding basic concepts such as
confidentiality, integrity, and availability helps individuals and
organizations improve their security.
